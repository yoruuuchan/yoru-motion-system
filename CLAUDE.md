# Claude Guide

Read [`AGENTS.md`](AGENTS.md) first — it holds the rules for working in this repo.

Then, in order:

1. [`docs/01-archetypes.md`](docs/01-archetypes.md) — which template came from which curated family
2. [`docs/02-motion-rules.md`](docs/02-motion-rules.md) — every measured constant and how it was measured
3. [`src/core/timing.ts`](src/core/timing.ts) — those constants in code
4. [`workflow/making-a-video.md`](workflow/making-a-video.md) — how the system is meant to be used

The companion repo is `yoru-motion-research`, which holds the curation snapshot, the
preference profile, the benchmark plan and the licence tracker. This repo implements;
that repo decides.
